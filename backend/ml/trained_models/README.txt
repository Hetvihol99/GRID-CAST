This directory stores trained XGBoost model files.

Files created by training scripts:
  solar_model.pkl        — trained solar XGBoost model
  wind_model.pkl         — trained wind XGBoost model
  scaler_solar.pkl       — StandardScaler for solar features
  scaler_wind.pkl        — StandardScaler for wind features
  solar_model_metadata.json
  wind_model_metadata.json

These files are gitignored — run training scripts to generate them.
